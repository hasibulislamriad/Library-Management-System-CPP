# Library Management System - C++

A console-based Library Management System built with **C++**, **Object-Oriented Programming (OOP)**, and **File Handling**.

## Features

- Add Book
- Show All Books
- Search Book by ID
- Issue Book
- Return Book
- Update Book
- Delete Book
- Library Statistics
- Persistent data storage using `books.txt`
- Input validation for menu choices

## Technologies

- C++
- OOP / Classes
- STL `vector`
- File Handling with `fstream`
- Standard Library

## Project Structure

```text
Library-Management-System-CPP/
├── main.cpp
├── books.txt        # created automatically when books are saved
└── README.md
```

## How to Run

### Compile

```bash
g++ main.cpp -o library
```

### Run on Linux / macOS

```bash
./library
```

### Run on Windows

```bash
library.exe
```

## Menu

```text
1. Add Book
2. Show All Books
3. Search Book
4. Issue Book
5. Return Book
6. Update Book
7. Delete Book

```
